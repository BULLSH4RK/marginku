# Override: Layar Bahan
- Kartu bahan: nama (title 16/600), `Rp X / satuan` (kanan, tabular), baris ringkasan (caption 12–14, `muted-foreground`).
- Satu aksi utama: FAB "Tambah bahan" (tinggi 56, `primary`). Pencarian di atas list, bukan di app bar.
- Form = bottom sheet (radius atas 24). Preview harga satuan live di bawah field; error di bawah field terkait.
- Hapus lewat swipe + tombol di sheet (alternatif non-gesture wajib). Bahan terpakai → pesan blokir menyebut nama resep.
- Empty state: ikon outline + 1 kalimat + tombol "Tambah Bahan Pertama".
